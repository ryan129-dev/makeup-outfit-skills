# 夜景橱窗：冷白透粉、细闪泪光与水润唇

## 风格配方
本方案以夜景中的可读妆面为重点，衣饰与环境光围绕面部安排。

- 底妆：明亮冷乳白底色透出玫粉，脸部柔雾至缎光，细微不规则纹理；鼻尖与颧骨只有小面积高点，不用全脸油光表现通透。
- 眼妆：淡玫粉眼睑，棕色只定义外睫毛根部，细眼线与短上扬眼尾，卷翘分束睫毛。银粉细闪集中上睑、内眼角和局部双侧下睫毛缘；局部湿润泪光，不流泪、不红肿。
- 唇颊：高位透明玫粉腮红，边界柔和；玫粉唇中央略深，唇缘自然清楚，水润连续反光。
- 服饰配件：深色露肩针织、小银耳饰，衬托明亮妆面；长深发与少量松散脸侧发丝。
- 实际场景：夜晚人行道与服装店玻璃橱窗，窗框、暖色顶灯、虚化衣架和陈列台可辨；远处街灯与车灯沿街道退远，湿地面有对应反射。背景有可信结构，不是空散景或抽象特效布景。
- 光与后期：中性白正面柔光清楚展示妆容，暖店灯与街灯留在环境，少量暖发丝边光；人物冷白透粉与低饱和暖夜景形成分离，保留黑发细节，光晕局限实际灯点，不给整脸蒙雾。

构图应保证妆面可读。换成暖色妆面时重新安排环境冷暖，不固定冷白肤色；保留窗框、店灯与街景纵深可维持现场感。
