# 环境人像：动作、服装与空间

以下三个案例来自 True JPEG「人像」Tab。这里记录画面中可见的构图关系和适用于成年人物的设计；图片是视觉参考，未生成验证，也未经过用户审美验收。拍摄设备与参数无法从画面确认。

## 海风甲板：白色造型与深色海面

参考：[True JPEG #027](https://truejpeg.com/#027)，网站展示 No.164。竖幅近全身，人物倚在船边栏杆前，双臂向后张开、手扶栏杆，躯干轻斜，一条腿弯曲向后；身体与横向栏杆交错。头低侧倾，眼睛朝镜头，嘴唇轻启，面前白色斜向饰带与风吹散的黑色长发形成明显线条。白色帽子、短外套与多层带状服装在深色海面前形成大面积明亮主体，外套下摆被风带向画面左侧。云层和海面都压暗，人物背侧的发丝边缘明显发亮；画面中有船架与栏杆形成的纵深。

**画面精髓**：明亮白色造型居中、深海和阴云作为大暗块；扶栏的双臂、斜倾头、随风向侧面延伸的发丝与衣摆共同制造动势。近全身裁切能让姿态和支撑关系读清，局部亮边把人物从复杂背景中分开。只保留白衣和海景、换成正面站姿与无风环境会失去原画面的运动感。具体服装结构、饰品与景点可按目标改变，但应保留清楚的手与栏杆接触、风向一致和人物亮于背景的层次。

**设计与检查**：为成年人物设计白色层叠时装和海上栏杆场景；以竖幅近全身安排身体斜线、扶栏手势及弯腿，头略倾并看镜头，让发丝和衣摆朝同一侧随风延展。深色海面、云层与明亮主体形成对照，发丝保留少量轮廓亮光。检查双手确实抓扶栏杆、动态未遮挡五官、白色面料有结构且亮部未丢失。

## 阴云工业道路：白色轮廓与深空间

参考：[True JPEG #034](https://truejpeg.com/#034)，网站展示 No.172。方形画面，人物居中跪坐于道路前景，身体直起、手臂位于身后，肩线略有倾斜；短黑发在脸旁形成不规则轮廓，头稍偏，视线向镜头，嘴唇微启。白色连体造型边缘有细红色线条和小面积红色点缀，与暗灰道路、围栏和工业建筑明显分开。道路标线及围栏向右侧远方收束，灰色积云占上方画幅；人物亮部在灰暗环境中突出，但背景设施与地面纹理仍可辨。

**画面精髓**：居中、低位人物与背后深远的单向道路形成前后对比；白色造型是一整块清晰的亮区，红线只是小点缀；松散短发、倾头和微启唇使脸部与姿态形成连贯的视觉焦点。改变服装时应保留白色主体与细小暖色点缀的比例，并让道路和围栏线条保持纵深；如果把背景改为纯黑、人物改成近景，工业场所的尺度感便会消失。

**设计与检查**：以方幅呈现成年人物低位跪坐于空旷的工业风摄影场景，身后道路标线向远处汇聚；白色结构化造型配少量红色边线，短发略凌乱，头轻倾并看向镜头。采用阴云下低饱和灰色环境和较明亮的前景照明假设，让衣物与肩脸有形体、背景仍可辨。检查跪姿与地面接触自然、道路线没有断裂，脸部表情不被压暗。

## 复古沙发：举臂与交叠线条

参考：[True JPEG #067](https://truejpeg.com/#067)，网站展示 No.202。竖幅室内全身画面，一张暗橄榄色花纹沙发占画面中段，人物坐于中间偏右位置；一臂从肩旁向上伸向画框上方，两腿交叠并向画面下方延伸，尖头高跟鞋与腿部形成细长斜线。深色短发带齐刘海，脸朝前、视线接近镜头，唇轻启；黑色蕾丝上衣与带花纹的黑色袜装在沙发上清晰可辨。淡暖色素墙位于人物后方，前景地毯偏暗，人物与沙发有较直接的亮面，四周渐暗。

**画面精髓**：沙发的横线稳定画面，抬起的手臂向上拉伸、交叠双腿向下形成斜线，构成完整的人物几何轮廓；黑色花纹与橄榄色沙发的质地对照，浅墙留白让手臂和发型清楚。调换服装或家具时可保留举臂、双腿方向与沙发横线的关系；若裁成半身或把手臂放下，会丢失这一姿态的节奏。

**设计与检查**：竖幅全身室内时装肖像，成年人物坐在带织物纹理的复古沙发上，一臂自然伸向上方，双腿交叠并向下延伸；短发和刘海构成脸部轮廓，神态由视线和嘴部状态具体决定。黑色纹理服饰与低饱和暖色家具对照，前景有直接照明感，墙面留出手势空间。检查手臂与肩部衔接、膝踝及鞋子形状、服装图案和家具纹理在暗处仍有区分。
