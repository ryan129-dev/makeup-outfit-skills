# 用户选定人像：神态、透视与暗空间

网站「人像」分类。展示编号与链接作品 ID 不同。以下是可迁移的画面关系。灯具、焦距未知。

## No.170：眨眼微笑与近距离室内直射光

来源：[True JPEG No.170](https://truejpeg.com/#028)。竖幅近距离人物，画面视角略高，人物向镜头方向微微前倾，双臂收在身后、手不可见；肩线和头部有轻微倾斜。画面左侧眼睛闭起、另一只眼睛看向镜头，嘴角上扬并闭唇，形成明确的眨眼微笑。深色头发中分向后整理，额头与脸部清楚；唇为柔亮粉色，眼妆精致，面颊带淡粉色。

中灰色短袖造型的领口和小面积金属环形成结构亮点；前景人物在明亮直接光下突出，后方暗色室内柜体只保留必要线条，头顶局部有较暖的亮边。**关键组合**是近距离略俯视、前倾肩线、单眼闭合加闭唇微笑，以及前景直接亮光对暗背景的分离。若换成端坐正面和双眼平视，会丢失轻快的抓拍感。可按主题调整服装，仍需保留明确神态、前倾动作和前后亮度关系；不要推测画外的手势。

**整体设计**：竖幅近距离抓拍，成年人物稍向镜头前倾，一眼自然闭合、另一眼望向镜头，嘴角上扬成闭唇微笑；中分深发向后收拢，露出额头，淡暖眼妆和粉色亮唇与灰色短袖造型协调。人物脸部和上身由近镜头方向的明亮光照出，背后深色柜体保留简单竖线，发顶有暖色反光。下方裁切可按用途调整，手留在画外。检查眨眼与笑容是否同步、脸和肩的倾向是否成立、背景未亮得抢主体；原图实际灯具和焦段未知。

## No.224：浅椅围合与冷色前景

来源：[True JPEG No.224](https://truejpeg.com/#086)。竖幅室内照片，人物坐在象牙白扶手椅中，黑色短发与齐刘海包住偏低的脸，眼睛向镜头看，嘴自然微分；身体后靠，前景肢体斜向交叠，呈现明显近大远小。深色长袖上装与浅青绿色反光面料形成色块对比，暖白椅沿在人物两侧勾出轮廓；画面右侧可见浅色床面，中央深色走廊向后延伸，并以一点暖光提供空间深度。

前景冷色表面有连续亮暗反射，黑发和上装衬托面部；直接感的近前方光与室内暗部并存。**关键组合**是低头看镜头的神态、浅椅围合、前景斜线及其透视、冷色亮面与暗房间中少量暖色纵深。可重设计服装及座姿，但需要先确保人物、椅子和前景的前后层次；只保留青绿颜色或把画面改成均匀柔光头像，会改变作品的空间效果。

**整体设计**：竖幅室内时装肖像，成年人物靠坐在浅色扶手椅里，脸位于画面中上部，低头从齐刘海下看向镜头，短黑发一侧有几缕横向飘出的发丝。让一条屈腿向前景斜伸并与另一条腿错开，以青绿色反光面料构成画面下半部的大色块；黑色高领上衣与象牙白椅背围合脸部。背景保留暗色房间、旁侧浅色床面和远处暖光走廊；使用近前方直接光的视觉效果，使冷色面料亮部连续、面部眼神清楚。可调整衣着细节与室内陈设，但应保留前后透视、椅背轮廓、近亮远暗和局部暖光。检查坐姿支撑、肢体连接与前景遮挡关系，避免让面料亮部变成无纹理白块。

## No.247：低机位对称构图与黑色材质

来源：[True JPEG No.247](https://truejpeg.com/#118)。横幅室内时装人像，从低处向上看，人物居中，脸位于上方中央，目光朝镜头方向、唇轻启；双臂向画面两侧伸出，手分别落在两侧，身体轮廓在宽画幅中近似对称。浅金色头发和手臂上的花卉图案与黑色服装相对照，黑色高领及蕾丝图案区域的细纹同旁边较亮的光滑表面形成材质差异。

室内四周暗，天花板及后方少量暖色光提供环境线索，人物和手部受较直接光照。两手分别落在身体两侧的前景部位，而不是支撑在墙上。**可迁移的是**低机位、中央人物与两侧延展手臂、对称节奏、暗室中的集中明暗和黑色材质的软硬对照。此处只提炼构图与光色，不作为完整原图的复现配方；人物姿态与服装按用途重新设计。

**局部迁移设计**：横幅低视角时装肖像，成年人物位于中央，以自然站姿或坐姿向两侧舒展手臂，脸保持在画面上方中心并朝镜头；黑色造型结合局部蕾丝纹理和少量硬亮材质，浅色发型与暗室形成反差。保留天花板、暗色墙面和一点暖色背景光，前方较直接的光照出面部及两侧手臂。让对称中存在轻微自然差别，并检查广角透视下手臂与肩的连接；具体相机参数与光源属于设计假设。
