# True JPEG 选定人像：视线、发型与光影

以下作品按网站显示的 No. 编号识别，链接中的数字是不同的作品 ID；四张均位于「人像」分类。仅提炼人物面部、服装材质、镜头与空间等可迁移的画面关系，属于部分提取，不代表完整复现原图。观察与设计均尚未通过生成或用户验收；未确认的灯具、焦段不当作事实。

## No.122：低垂眼神与亮窗暗室

来源：[No.122 / #193](https://truejpeg.com/#193)。竖幅中人物靠近镜头，脸位于上方中央且头顶裁切，观察视角略低，暗色长直发与灰色室内形成低明度框架；人物身后的亮窗被横向条带切分。头略低、双眼朝下，睫毛清晰，唇微启；棕粉眼影从上眼睑过渡到外眼尾，粉色腮红与偏玫瑰的亮唇形成柔和色彩。眼睑、鼻尖与唇部有局部亮点，亮窗明显比背景暗墙明亮。

**可迁移关系**：靠近的竖幅裁切、低头向下的视线与深发包围的脸一起产生近距离感；亮窗的水平线让暗室仍有空间结构。以头肩肖像应用时，用少量前方补光保留睫毛和唇色，同时保留亮窗与低明度室内的对比。画面中不清楚的光位和窗外细节不作推断。

**设计与检查**：为新成年人物设计竖幅头肩近景，人物靠近镜头、头轻低而眼睛看向画外下方，深色直发在两侧围合脸部；棕粉眼影、清晰睫毛、粉颊与玫瑰亮唇共同构成重点。人物身后保留水平条带分割的明亮窗面和较暗室内，脸部有少量前方光。检查头顶裁切、视线、眼唇细节与窗面明暗层次是否同时成立；该版本仅迁移面部神态与光线，不声称完整复现原画面。

## No.141：暗色街景、灰牛仔与回望

来源：[No.141 / #003](https://truejpeg.com/#003)。竖幅街头人像，画面偏高角度，人物略侧身并抬眼看镜头，头轻偏，唇自然微启；深色长发分到两侧，眉眼有细长上扬眼线，唇色偏玫红。灰黑色牛仔外套和同色牛仔裤构成深色主调，一手靠近衣领，另一手落向裤袋，肩上的棕色包带形成窄对比线。近处脸部与手较亮，身后的斑马线、树干和建筑较暗，线条仍可辨。

**可迁移关系**：画面从头部裁到腰胯附近，微俯视、略偏的头与看镜头的视线、手靠近领口以及另一手靠近裤袋共同形成抓拍感；斑马线斜向穿过身后，亮面部、双手与灰牛仔缝线从深色街景中突出，棕色包带只承担窄面积点缀。保留人物与道路的方向关系、前景直射感及可辨的牛仔接缝，才能留住都市夜拍结构；实际光源设备未知。

**设计与检查**：竖幅夜街时装照，以略高角度拍成年人物，灰黑短款牛仔外套和同色牛仔裤有清楚的浅色缝线；一手靠近领口、另一手放近裤袋，细棕色肩包带沿肩侧落下。脸稍转向镜头，眼线略上扬、唇为玫红；斑马线在后方斜穿，人物与前景被较直接的亮光照明，树木和建筑留在暗处。检查两手落点、标线方向、脸部亮度和牛仔纹理，服装具体款式可按任务调整。

## No.147：露台城市光点与银色饰品

来源：[No.147 / #009](https://truejpeg.com/#009)。人物位于画面右侧，身体面向栏杆，头越过肩线转回，眼睛透过偏低的细框眼镜看镜头，双唇轻启并有粉色光泽；手落在画面左侧的深色栏杆上。短黑发与夜空衔接，银色十字造型的耳饰、颈饰及链状饰品在暗色背景与服装上形成点状和线状亮点；远处城市窗光零散分布。

**可迁移关系**：人物位于画面右半部，头在上方转回镜头，一只手落在左侧栏杆，肩与手臂构成从右上到左下的斜向连接；低位眼镜让双眼与镜框共同形成视觉焦点。银色耳饰、颈饰和细链在脸周及手边形成小面积连续反光，远处散落城市灯点则提供纵深；近处脸与肩明显亮于深蓝黑夜景。必须把回头、扶栏、眼镜与近亮远暗的城市层次放在一起；只取银饰和城市灯光会失去原来的人物关系。

**设计与检查**：竖幅都市露台人物照，成年人物位于画面右侧，身体侧向栏杆、头回转看镜头，手自然扶住左侧栏杆；低位细框眼镜、深色短发、银色耳饰与颈饰共同围绕面部。画面一侧留出低亮度城市建筑和零星灯点，近处用直接感光线照亮人物与金属细节。检查眼神与眼镜位置、手栏接触、饰品垂落方向和城市远近层次；服装与饰品样式可按任务重新设计，不把设备型号当成事实。

## No.148：暗室肩侧回望与黑发框脸

来源：[No.148 / #121](https://truejpeg.com/#121)。横幅暗室图，人物从上方偏中间的面部向画面右下延伸，面部稍偏左，左侧保留大面积暗空间；身体朝向与回转看镜头的脸错开，手臂向下支撑在前方。黑色齐刘海、脸旁短发和向后垂落的长发围住面部；眼睛睁开且视线直接，唇微启，粉色眼颊和亮唇从暗背景中分开。地面深色线条向远处延伸；肩背侧明亮，黑色细带在服装上交叉。

**可迁移关系**：横幅的主体偏置与左侧暗空间、身体和头的反向、黑发框住明亮面部与肩部、交叉细线及室内纵深共同支撑画面。眼睛直接看向镜头，而不是顺着身体方向看，形成明确视线焦点。只将其改成普通正面头像会丢掉头肩方向差与横幅留白。实际灯位无法确认；这里可提炼头肩和空间关系，并非完整复现参考。

**设计与检查**：横幅暗调室内人像，成年人物身体侧向画面右方，肩线与转回镜头的脸形成方向差，画面左侧留暗空间。深色齐刘海与两侧直发围合脸部，粉色眼颊、清楚睫毛与柔亮唇色可辨；较直接的前方光让面部及肩部突出，暗室地面线条保留透视。按用途设计与动作相称的深色服装，检查头肩转向、眼神、负空间和亮暗层次。
