# 结果判断与修正

依据本次请求验收，不把所有专业标准套到每项任务。

|交付|判断重点|
|---|---|
|分析或答疑|判断是否回答问题、可见证据是否支持解释、推测是否标明、建议是否适用于当前条件|
|提示词或方案|是否可执行、是否覆盖关键关系、内部有无矛盾、范围和参考角色是否正确；未出图不评为效果已验证|
|图片或编辑|目标是否在实际展示尺度下成立，关键结构与风格是否正确，保留项有无漂移；只检查实际可见结果|
|比较或选择|比较条件是否一致、差异是否影响用途、选择理由是否具体；不将个人偏好写成普遍定论|

人物身份、妆效、画风和整体美感分开判断。技术正确不能抵消实际不好看；美感达标也不能抵消本人失真或明确要求遗漏。助手观察与用户认可分别记录。

## 反馈定位

|现象|区分原因|修改方向|
|---|---|---|
|效果准确但用户不喜欢|目标理解或偏好不符，未必是工具失败|修正视觉目标与取舍，不单纯加强原配方|
|方案适合但图没实现|关键描述缺失、相互抵消或工具执行偏差|对照实际图定位主要差异，改提示或执行方式|
|只换颜色却没换风格|形体、线条、材质与构图未变|改造成画风差异的表达方式|
|妆更明显但不好看|范围、边缘、色彩或主次失衡|调整问题部位与组合，不继续全脸加浓|
|妆造过满或像舞台妆|同时突出的部位、饰品和反光过多，或借用了未要求的华丽案例|减到一个重点，降低饱和、反光和装饰数量|
|换人后失效|把原脸、肤色、姿态或比例误当通用条件|重做人物适配，保留有效关系|
|局部修复改变整图|编辑边界不清或工具产生漂移|缩小修改范围，支持遮罩时使用，并复查非目标内容|

按对任务的影响确定修复顺序。身份或结构错误通常优先；探索新方向可整体重设计，修复已认可作品保留已通过部分。遵守用户指定的次数、时间和成本；未指定时采用有限尝试，连续尝试未改善则调整方法或报告限制。

单次失败只支持当前条件下的结论。未明确原因的“不喜欢”不能推导为对某种颜色、衣服或风格的永久否定；修改知识按[参考学习](../workflows/reference-learning.md)执行。
