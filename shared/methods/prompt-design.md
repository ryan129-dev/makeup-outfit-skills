# 视觉规格与提示词

把设计决定写成可见关系，按请求和目标工具选择内容。纯文字请求在提示词完成后交付；图片请求继续调用工具，并检查实际结果。

## 从目标到描述

|需要控制的内容|描述方式|
|---|---|
|主体与任务|生成或编辑什么、表现形式、用途及关键对象；身份与风格参考分别指定|
|画面组织|景别、主体位置、视角、裁切、前后层次；按用途决定画幅|
|可见效果|颜色及面积、线条、形体、边缘、材质与反光，避免只有审美形容词|
|动作与联系|头肩和视线各自朝向、手与物件的接触、结构或遮挡；左右注明人物或画面坐标|
|照明与后期|主光方向和软硬、主体与环境亮度、色调和细节保护；避免相互抵消|
|修改边界|目标部位、希望变化的效果、范围外保留项；完整创作不照搬局部编辑的冻结句|

只展开影响本次目标的维度，不机械填满参数卡。整体设计先解决主要关系，再补对结果有贡献的细节；限定输出为短提示词时优先保留决定性关系。

## 冲突处理

- 强弱描述限定部位：柔雾皮肤可搭配湿亮唇，柔边眼影也可以显色；不同时要求整张图完全哑光又处处湿亮。
- 指定画风后使用对应的形体、边缘与质感，避免用照片级毛孔抵消动漫或绘画表达。
- 重要限制具体写明，少量排除项用于已知偏差；长缺陷清单不能替代可执行的手势和空间关系。
- 未选工具时给语义规格。只使用工具实际支持的字段；参考强度、seed、步数等不设跨模型通用数值。摄影数值可表达意图，不能保证生成结果或人物身份。

## 适配示例

目标为保留现有照片、仅换深灰羊毛外套：描述外套轮廓、落点、哑光纤维与受力褶皱，并明确保留脸、妆发、姿态、背景、身体比例，以及没有点名的衣、裤、鞋。目标为重新设计完整时装照：同样的外套描述可复用，但姿态、构图和光线应重新服务完整目标。

“通透”要按对象展开：皮肤可能需要柔和明暗和局部反光，玻璃需要透射、边缘折射与背景可见，插画可能通过薄色层与留白表达；不能共用一段水光词。

## 执行

生成前核对参考角色和文字内部一致性。人像、妆容、穿搭的质量目标写成[好看的量化](look-quality.md)中对应的可见关系；「出片」「惊艳」「有感觉」按当前主体与用途具体化，不自动增加饱和色，也不将其作为独立评分域。明确的光色请求可描述亮暗、颜色与细节保护，但本页不为其提供专门分数。

完整人像与妆容任务写清本次妆造、可见服饰和人物比例，画面组织见[人像](portrait-figure.md)。普通穿搭与 OOTD 写衣物、比例、姿态和对应版式，不强制写眼妆或人像布光；只有用户同时要求妆容设计时才补充对应妆容规格。

生成后用[结果判断](result-review.md)检查目标是否实现；提示词写得具体不代表效果已实现。工具不支持所需控制时说明实际限制，不伪造操作。纯文生图探索的限制见[参考学习](../workflows/reference-learning.md#无参考图探索)。
