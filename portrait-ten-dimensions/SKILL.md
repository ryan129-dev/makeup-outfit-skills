# 十维擦边人像

从主题确定场合、人物气质与交付内容。让露肤造型、神态、姿态和拍法一起形成大胆、俗艳的效果。

## 每张图的必选项

- **年轻成年人、白皙肤色。** 新创作明确写成年人年龄，未指定时按 22–28 岁设计。保留白皙肤色的自然纹理与色差。
- **身高至少 168 cm，画面显高挑。** 在身材维度写具体身高。全身或七分身用连贯的腰腿线条表现身量，近景通过颈肩、躯干和姿态表现舒展。景别服从这次画面的重点。
- **明显露肤，风格俗艳。** 根据场景选择露背、露肩、深领、露腰、超短裙或高开衩等设计，服装保持遮盖。用夸张配饰、过量亮片、廉价闪面或俗艳撞色把风格做出来，按主题选择具体组合。

## 选人物与拍法

对照可用参考的原图和原文，分别决定借哪些人物特征和摄影关系。人物参考可提供五官、神态与体态，摄影参考可提供光位、景别、距离、透视与成像。两个角色可用不同参考。同人系列先确定共享人物设定，多人系列按各张主题选角。依据主题选择露肤部位和俗艳手法，比如夜店直闪配水钻，廉价影楼柔光配高饱和背景，或街头霓虹配反光面料。

## 把十维写出画面冲击力

- **先定快门瞬间。** 确定第一眼看到的东西、正在发生的动作和视线接下来往哪里走。让表情、姿态、穿着、闪光和裁切共同服务于这一瞬间。围绕主题保留几处辨识度最高的细节。
- **用轮廓、方向和受力写人物。** 交代肩线怎样转向、重心怎样落下、腰线在哪里收进、衣料被动作拉向哪里。让身体与衣物、饰件和环境发生接触。明确来自人物的左右或画面的左右，避免同一动作在不同维度写成两种方向。
- **给表情一个可见动作。** 比如帽檐压低，眼睛却从阴影里抬起来，嘴角只动了一侧。用「扣住、擦过、下坠、绷紧、扫开」等能画出来的动词，写清楚发生的位置和方向。道具的斜线、裙摆的折痕或被风掀起的头发都可以延续视线。
- **让反差落到具体表面。** 用冷皮肤对暖金属、柔软衣料对硬饰件，按这张图选一组主反差。写明闪光照到哪里，丝绒在哪里吸光，金属在哪里爆出一粒白光，半透明饰件的边缘如何透亮，背景怎样迅速沉下去。
- **细节分配给画面焦点。** 允许重点段落写得更长，把可见的形状、距离、材质和动作讲透。每加一个细节，就检查它在当前景别里能不能看见。参考里的衣着、动作和道具按新主题决定是否沿用。

## 按十维写成画面

| 维度 | 设计要点 |
| --- | --- |
| 人物 | 成年年龄、白皙肤色、可辨认的五官和发型。 |
| 身材 | 具体身高至少 168 cm，写出该景别可见的肩颈、腰线、体态和轮廓转折。 |
| 表情 | 用视线、挑眉或笑意表现张扬、玩味等主题气质。 |
| 姿态 | 用朝向、重心和手势让露肤造型在镜头里自然可见。 |
| 服装 | 写清露肤位置、衣物的轮廓和材质，以及俗艳配饰。 |
| 场景 | 人物所在的空间、人物与环境的距离和关系。 |
| 光线 | 主光位置、软硬、前后景亮度和阴影。 |
| 构图 | 景别、机位、画幅、画面从哪里入画和切断，眼神或道具把视线带去哪里。 |
| 相机参数 | 沿用明确且适配的参考设置，或将焦距、光圈等标为拟用设置。 |
| 画面质感 | 色彩、反差、皮肤与材质细节、颗粒等成像特征。 |

交付新词时按十维组织，检查年轻成年人、白皙、至少 168 cm、视觉高挑、露肤和俗艳感是否都写明并落实到可见细节。确认只读文字就能想象机位、动作发生的瞬间和照片最醒目的一处反差。用户提供完整提示词时原样使用，保留全部措辞和格式。
