# 十维人像设计

从人像主题确定画面要表达什么，以及最终交付方案、提示词还是成片。按主题决定哪些细节值得展开。用眼神、动作和人物与环境的关系表达气质，让姿态、机位与用光服务于同一个画面目标。

## 选人物与拍法

对照可用参考的原图和原文，分别决定借哪些人物特征和摄影关系。人物参考可提供五官、神态与体态，摄影参考可提供光位、景别、距离、透视与成像。两个角色可用不同参考。同人系列先确定共享人物设定，多人系列按各张主题选角。场景、动作和衣着依据本次主题设计。

## 按十维写成画面

| 维度 | 设计要点 |
| --- | --- |
| 人物 | 选角、可辨认的五官特征、发型和整体气质。 |
| 身材 | 头身比例、骨架和体态，与姿态、景别相容。 |
| 表情 | 视线、眉眼和嘴角呈现的神情。 |
| 姿态 | 身体朝向、重心、手势及与环境的接触。 |
| 服装 | 衣着轮廓、材质与颜色，符合人物和场合。 |
| 场景 | 人物所在的空间、人物与环境的距离和关系。 |
| 光线 | 主光位置、软硬、前后景亮度和阴影。 |
| 构图 | 景别、机位、画幅、主体位置和裁切。 |
| 相机参数 | 沿用明确且适配的参考设置，或将焦距、光圈等标为拟用设置。 |
| 画面质感 | 色彩、反差、皮肤与材质细节、颗粒等成像特征。 |

交付新词时按十维组织，检查选角、表情、承重、衣物、景别和光线能否同时成立。用户提供完整提示词并要求照原文使用时，保留全部措辞和格式。
