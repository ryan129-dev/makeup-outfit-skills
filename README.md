# 妆容与穿搭研究 Skills

用于研究参考图、提炼可迁移配方、固定人物生成或编辑，并检查实际结果。

根据妆效意图识别：在人物妆容、写真或修图语境下，提到冷白皮、冷白透粉、白里透红、布灵布灵、bling bling、珠光眼妆或眼周细闪等效果时使用妆容 Skill。Skill 主动分析上传图片：身份参考用于为本人设计，风格参考用于提炼并融入指定视觉特点；同一张图可兼具两种用途。默认主导妆容、发型、神态动作、服装配饰、场景、构图、光线与后期，无身份图时设计新成年人物，不设固定默认妆容。泛泛的人像生成请求不触发本 Skill；珠宝、服装等对象的闪光描述也不触发妆容流程。

## 使用

默认生成独立单张成片；宫格仅是历史验收的比较方式，不是 Skill 约束。多个风格版本可分别选用，不要求同时生成；多张默认分别交付，仅当用户明确要求时拼成宫格。

让助手读取所需目录的 `SKILL.md`，按需提供身份图、风格图和本轮目标。安装时将两个顶层目录一起复制到所用客户端的技能目录并保持相邻，以便穿搭 Skill 读取妆容目录中的共享风格卡。妆容目录内的案例通过相对路径按需读取；若要独立调用冷白透粉案例，也可将其单独复制到技能目录。

不包含人物照片、账户配置或模型权重。冷白透粉风格已在一次指定人物编辑中获得用户认可；跨人物、跨模型的稳定性尚未验证。玫瑰棕四版完整造型已在一次有身份图四宫格中获得用户认可，涵盖妆容、配饰、穿搭与神态；跨人物、跨模型稳定性未验证。

## 持续学习参考图

收录精美的风格、妆容、穿搭及配饰：观察参考图，提炼色彩、尺度、留白、材质和反光的关系，再保存独立风格卡。仅分析、已试图与用户认可分别记录；用户弃用的案例不作为正向配方。使用时结合人物、用户要求和画面选择并调整合适的风格；没有参考图或没有指定风格时，自动设计精美协调的完整造型，不固定套用同一套配方。用户明确限定局部或指定风格时，遵循当轮要求。

人物画风与妆容穿搭分开选择：真人摄影、插画和 3D 等表现方式可使用各自适配的造型；用户指定画风时按要求应用。真人写真不会仅因为风格库包含插画而自动变成插画。
